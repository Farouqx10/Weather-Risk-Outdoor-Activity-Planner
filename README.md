# 🌍 Weather Risk & Outdoor Activity Planner

An AI-powered weather and outdoor activity recommendation app built with Python and Streamlit.

The app analyzes live weather conditions and helps users decide whether outdoor activities such as football, jogging, farming, picnics, travelling, and outdoor events are safe.

---

## 🚀 Features

* 🌦️ Live weather forecast using Open-Meteo API
* 🧠 AI-powered activity recommendations with Gemini API
* 📊 Risk analysis (Safe, Manageable, Risky, Avoid)
* 🕒 Best time suggestions for activities
* ⚠️ Weather safety tips
* 🎒 Packing checklist generation
* ⭐ Favourite locations
* 📜 Search history storage
* 🌍 Real location search
* 🎨 Modern Streamlit UI

---

---

## ▶️ Run the App

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the app:

```bash
streamlit run app.py
```
